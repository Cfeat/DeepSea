# 深海 · Deep Sea

面向中文读者的海洋科普网站，使用 React 19、TypeScript 和 Vite。线上地址：[深海](https://www.cfeat.cc.cd/DeepSea/)。

## 本地运行

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Vite 的默认地址是 `http://localhost:5173/DeepSea/`。浏览器回归测试启动独立的生产预览服务，使用 5176 端口。GitHub Actions 在数据测试、构建和浏览器测试通过后发布 GitHub Pages。

## 页面与数据

- 垂直深度轴是主要体验，保留滚动下潜、左右交替的生物卡片、深度和压力读数、海层跳转。
- 浅水区按卡片所需空间展开，稀疏区压缩空白；海洋雪、热液喷口、鲸落、海底地形、海沟和深度测量构成六个科普停留点。
- 图鉴可搜索中文名、英文名、学名和特征，支持收藏与跳回深度轴。百科链接使用 `?creature=<id>`，直接访问即可打开对应条目。
- 收藏、已读记录和下潜位置保存在当前浏览器。存储被禁用或数据损坏时，仍可阅读；“继续上次下潜”由读者主动选择。
- 实验室包含海水压力估算、柔软密闭气囊的玻意耳定律示范、从下方观察的反照明示范。计算条件放在折叠说明中。
- 原生 dialog 支持 Esc、焦点约束、关闭后焦点和滚动位置恢复。界面适配手机和减少动态效果偏好。

`src/App.tsx` 管理页面、筛选、收藏和条目链接；`components/DiveExplorer.tsx` 管理轴上交互；`utils/diveLayout.ts` 是海层、刻度、跳转和读数共用的双向坐标映射。该轴明确为非等比例的阅读轴，所有条目均保留，相同深度条目堆叠排列。

`data/creatureData.ts` 是唯一生物数据集，包含 37 个物种或类群条目。`data/types.ts` 定义科学资料结构，`data/media.ts` 保存已核对的图片出处、原图 URL、署名和许可。`data/topics.ts` 管理科普停留点，`data/science.ts` 管理压力、气体体积模型和通用资料。

## 科学口径

每条资料分别记录：

- `displayDepth`：轴上的示意位置，不能作为观测或下潜纪录。海层分组由此位置计算。
- `habitatRange`：仅在所引资料提供适用于条目的数值时填写，必须注明典型分布、类群汇总等适用范围。
- `depthRecord`：文献报告的观测或标签纪录，包含年份、解释和独立出处，与日常栖息范围分开。
- `scientificName`、`taxon`：区分单一物种与属、科等类群。旧 ID 为保持链接和收藏兼容可能与当前中文名不同，例如 `hadal-jellyfish` 现在对应 Atolla 皇冠水母。
- `sources`、`reviewedOn`：条目级机构资料或原始研究，以及整理日期。整理日期不表示原研究发表于当天，也不保证后续纪录没有变化。

海层边界使用常见教学划分，实际光照受海域和水体影响。压力使用 `P = P₀ + ρgh`，固定海水密度 1025 kg/m³ 和重力加速度 9.81 m/s²，输出绝对压力近似值。气囊模型使用等温、固定气体量、内外压力平衡的假设。反照明示范采用相对亮度，不是生物视觉的实测模型。

## 图片维护

原有来源不明的图库和搜索下载脚本已移除。当前十张照片来自明确署名的 NOAA 图片，逐张保留原始页面和原图 URL，按 NOAA 许可说明注明美国公有领域及作者。图片本地压缩为 WebP，页面无需连接第三方图片服务器。

缺少可确认许可的照片时，使用本站绘制、明确标注的简化形态示意图，不按比例，不用于物种鉴定。不能把机构网站的所有图片都视为可转载，也不能把搜索引擎结果当作图片授权。

添加条目前应核对对应学名、资料范围与图片主体。不要把极端观测写成典型行为，不要将某个物种的特征套用于整个类群。

## 验证

`npm test` 检查模型、海层边界、唯一 ID、资料字段、图片文件、展示位置与范围一致性、所有条目的布局完整性、同深度分组、防重叠间距及坐标往返换算。

`npm run test:e2e` 使用桌面和手机两种 Chromium 视口，验证学名搜索与定位、百科 Esc 关闭及原位恢复、收藏和阅读记录恢复、下潜续读、分享链接、互动实验、内容溢出，以及图片或浏览器存储失败时的阅读操作。
