# 两款游戏的玩法改进

这次改进把主要选择放进可重复游玩的规则中：文字游戏需要安排一趟有限储备的调查，经营游戏需要在期限内选择发展路线。故事、数值、界面和素材均由本站制作，没有移植参考游戏的剧情或资源。

## 深渊来信

核心循环是：选择地点 → 估算航速、消耗和风险 → 处理现场 → 决定继续、补给或返回。

- 九处地点构成互通航线。可以绕路、折返，已知路线更安全；主井需要取得路线线索后才能前往。
- 三种航速具有不同的氧气、电量消耗和碰撞风险。选择较快航速省氧，但耗电和紧张度更高；每段航行都推进一回合。第 22 回合起海况转坏，继续调查会有额外成本。
- 四件装备选择两件。装备会改变调查、救援和突发情况的处理方式；四格货舱中的氧气、电池和补修物资可以消耗或丢弃。现场物资只能领取一次。
- 三种目标分别侧重救援、研究和完整调查。第 20 回合后由母船接走失联人员，个人救援机会结束，后续调查仍可进行。
- 三组记录中选择两组并给出解释。符合原始记录的电气故障判断解除校验锁；错误解释消耗储备、增加紧张，但允许重试。
- 正常返回需要按深度预留资源。应急信标可以保全人员，但会放弃潜器和货舱；完整档案是否带回单独记录。六种结局保留不同完成程度。

重要操作后，日志说明结果；航线面板持续展示目标、救援窗口和回程成本。现场调查与航行笔记可以快捷跳转，手机端不用反复滑过整页。

## 深海前哨

核心循环是：查看海况与明日收支 → 调配人员和设备 → 安排建设、研究、委托或考察 → 推进一天 → 处理反馈。

- 三个海域改变发电、科研或维护条件。三种项目目标分别要求通信网络、人员生活或低扰动调查，单一建设配方不能完成全部目标。
- 房间具有位置收益：热源位置利于发电；加工舱邻接发电舱、实验舱邻接信标有产出加成。居住舱靠近水培利于士气，靠近工业设备会有负面影响；迎流位置增加坏海况下的维护压力。
- 加班提高即时产出，也积累疲劳。轮休能恢复队员和生态，但产出较低；空闲人员同样参与恢复。配餐会改变食物需求、士气和疲劳。
- 制氧和水培先获得电力，其他设备按生活、科研或工业优先级供电。电力不足只停下未获得供电的设备，明日表格给出每间房的实际产出和停产原因。
- 海况按固定周期变化，显示三日预报；暴风会提高补给价格和考察风险，浑浊影响水培，海流影响发电。
- 六类考察有不同深度、科技和艇级要求。谨慎准备多花一天、风险低、资料更多；集中打捞更快、合金多，但风险和生态代价更高。结果在出发时确定，读档不能重抽。发生意外可以付出备件取回完整成果，或召回并接受部分成果。重复考察收益逐次降到 40%。
- 每六天更换两份委托，一次只能执行一份。交付消耗真实库存，完成获得经费或科研与声誉；取消或逾期损失声誉，同一轮不能反复接取同一委托。
- 科研、首航和供给稳定提供一次性阶段奖励。三十天内完成项目后可以继续自由经营，后续海况、疲劳、委托和设备维护继续生效。

## 规则与存档

新开局使用第二版存档，两款游戏的存储键互相独立。初始设置、固定随机种子和全部操作是存档的依据；导入时依照版本重新演算。导入资源数字、伪造结果、未知操作和不可执行的行动历史不能覆盖现有游戏。

第一版存档保留原规则，包括原叙事顺序、考察、事件和评估条件。页面显示版本提示，玩家可以继续、导出或自行重开第二版，不会在读取时悄悄改变旧进度。

## 验证

规则测试覆盖六种文字装备组合的完整调查、不同航行报告、资源与一次性奖励限制、推理纠错，以及三海域、三项目、两难度、三事件种子的 54 组经营通关。经营边界测试检查限时委托、供电、疲劳、任务风险、接应决策及无效存档。

桌面和手机的浏览器测试通过实际按钮完成新文字调查和新经营项目，验证自动保存与刷新恢复、自由经营、委托取消确认、旧版继续游玩和原有网站的阅读功能。
